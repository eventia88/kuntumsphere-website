# Kuntum Sphere

Laman statik Kuntum Sphere untuk GitHub Pages. English ialah halaman utama dalam `index.html`, manakala BM ada dalam `bm.html`. Pilihan bahasa berada pada menu. Tiada sistem pembayaran atau borang yang menyimpan data pelanggan. Butang pertanyaan membuka WhatsApp atau aplikasi e-mel pengunjung.

Bahagian Portfolio sudah disediakan. Isikan nama, pautan dan penerangan projek pelanggan selepas mendapat butiran serta izin untuk memaparkannya. Jangan gunakan nama majikan atau pelanggan yang belum mengesahkan kolaborasi.

## Terbitkan

1. Muat naik fail dalam folder ini ke akar repositori GitHub awam.
2. Dalam **Settings → Pages**, pilih **Deploy from a branch**, `main`, `/ (root)`.
3. Dalam **Custom domain**, masukkan `www.kuntumsphere.com` dan simpan. Fail `CNAME` dalam projek ini menyimpan nama itu.
4. Di DNS domain, tetapkan CNAME `www` kepada `eventia88.github.io`.
5. Selepas DNS disahkan, hidupkan **Enforce HTTPS**. Untuk versi tanpa `www`, ikut rekod A atau ALIAS yang dipaparkan oleh panduan GitHub.

Kandungan English boleh dikemas kini dalam `index.html`, kandungan BM dalam `bm.html`; gaya pilihan bahasa dan Portfolio dalam `bilingual.css`.
